# BA Copilot - Architecture

## Overview

BA Copilot is a multi-agent AI system designed to automate Business Analyst deliverables from a business requirement document.

The system follows an Agentic AI workflow where specialized agents collaborate to transform requirements into structured BA artifacts.

---

```text
                 +----------------------+
```

# Core Components

## 1. Document Processor

### Purpose

Responsible for ingesting requirement documents.

### Current Support

- TXT documents

### Planned Support

- PDF documents
- DOCX documents

### Responsibility

Converts documents into plain text that can be processed by agents.

---

## 2. Workflow Orchestrator

### File

```text
workflow/orchestrator.py
```

### Purpose

Acts as the central coordinator for the agent workflow.

### Responsibilities

- Executes agents in sequence
- Maintains workflow flow
- Updates workflow state
- Generates final report

### Similar Concept

Comparable to:

```python
Runner.run()
```

in OpenAI Agents SDK.

---

## 3. Workflow State

### File

```text
workflow/state.py
```

### Purpose

Stores intermediate and final outputs generated by agents.

### State Attributes

```python
analysis
stories
acceptance_criteria
story_gaps
effort_estimation
review
refinement
```

### Benefits

- Shared context between agents
- Easier debugging
- Scalable architecture

---

## 4. Base Agent

### File

```text
agents/base_agent.py
```

### Purpose

Common parent class for all agents.

### Responsibilities

- Prompt loading
- LLM initialization
- Shared functionality

### Benefits

- Reduces code duplication
- Easier maintenance

---

## 5. Provider Factory

### File

```text
core/provider_factory.py
```

### Purpose

Centralized model provider selection.

### Example

```python
ProviderFactory.get_provider()
```

### Benefits

Allows switching between:

- Mock Provider
- OpenAI Provider
- Claude Provider
- Ollama Provider

without modifying agent implementations.

# Agent Design

## Requirement Analyzer Agent

### Input

Business Requirement

### Output

```json
{
  "actors": [],
  "modules": [],
  "functional_requirements": []
}
```

---

## User Story Agent

### Input

Requirement Analysis

### Output

```json
{
  "user_stories": []
}
```

---

## Acceptance Criteria Agent

### Input

User Stories

### Output

```json
{
  "acceptance_criteria": []
}
```

---

## Gap Analysis Agent

### Input

User Stories

### Output

```json
{
  "gaps": [],
  "clarification_questions": []
}
```

---

## Effort Estimation Agent

### Input

Analysis + Stories + Acceptance Criteria

### Output

```json
{
  "complexity": "",
  "story_points": 0,
  "estimated_days": 0
}
```

---

## Review Agent

### Input

Generated BA Report

### Output

```json
{
  "quality_score": 0,
  "strengths": [],
  "issues": [],
  "recommendations": []
}
```

---

## Refinement Agent

### Input

Review Results

### Output

```json
{
  "improvements": [],
  "final_quality_score": 0
}
```
